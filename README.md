# 👻 Last Light

A single-file, browser-based horror escape game. You wake up in an abandoned asylum
with a flashlight and a ghost hunting you. Find two rusted keys, reach the sealed
door, and escape before time runs out.

## Features
- Top-down, third-person view with a flashlight cone and dynamic darkness
- A ghost that patrols the rooms, hears noise, chases on sight and searches lockers
- Stealth tactics: sneak, sprint (loud), hide in lockers, throw bottles to lure her away
- Sanity system with flickering light, whispers and hallucinations
- Three difficulty levels: Easy (5:00), Medium (3:00), Hard (1:30)
- Round mini-map, sound on/off toggle, and a full-screen jumpscare
- Start screen and three endings: escaped, caught, or out of time

## Controls
| Key | Action |
|---|---|
| WASD / Arrows | Move |
| Mouse | Aim flashlight |
| Shift | Sprint (loud) |
| C | Sneak (silent) |
| E | Hide in locker / unlock door |
| Click or Q | Throw a bottle |
| M | Toggle sound |

## Run it
Open `index.html` in any modern browser. No build step or dependencies.
